Приклади запуску
Усі команди виконуються з папки labs/lab02/ при активованому віртуальному середовищі.
1. Запуск режиму demo (Демонстрація ООП)Ця команда запускає Завдання 1: створює користувачів, тестує валідацію пошти, права доступу та механізм аутентифікації.
PowerShellpython main.py demo
2. Запуск режиму analyze (Парсинг логів)Ця команда запускає Завдання 2: аналізує файл data/auth.log на наявність брутфорс-атак (за замовчуванням шукає понад 5 спроб за 5 хвилин).
PowerShellpython main.py analyze
3. Запуск режиму analyze з власними параметрамиПошук IP-адрес, які зробили понад 3 невдалі спроби входу протягом 10 хвилин, зі збереженням звіту у кастомний файл:
PowerShellpython main.py analyze --threshold 3 --window-min 10 --output-json "data/my_report.json"
Опис параметрів CLI
Головний скрипт використовує модуль argparse для обробки команд. Доступні дві основні команди: demo та analyze.
Для команди analyze доступні наступні аргументи:
| Аргумент | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `--auth-log` | `str` | `data/auth.log` | Шлях до вхідного лог-файлу, який потрібно проаналізувати. |
| `--threshold` | `int` | `5` | Поріг блокування (мінімальна кількість невдалих спроб для спрацювання тригера). |
| `--window-min` | `int` | `5` | Часове вікно у хвилинах, протягом якого рахуються спроби. |
| `--output-json`| `str` | `data/blocklist_ips.json` | Шлях до файлу, у який буде збережено фінальний звіт у форматі JSON. |
Щоб переглянути довідку безпосередньо в терміналі, введіть:
PowerShellpython main.py --help
python main.py analyze --help
Поведінка при помилкахПрограма має вбудовану обробку винятків (try/except) для забезпечення стабільної роботи:
Невалідний Email: При спробі призначити користувачу некоректну електронну адресу (наприклад, таку, що починається з цифри), генерується ValueError. У режимі demo ця помилка безпечно перехоплюється, виводиться відповідне повідомлення, і виконання програми продовжується.
Відсутність лог-файлу: Якщо при запуску analyze вказаний auth.log не знайдено за заданим шляхом, програма виведе дружнє повідомлення про помилку (FileNotFoundError) замість раптового падіння.
Помилки імпорту спільних даних: Якщо не вдається імпортувати дані студента з shared.student, програма використовує безпечні значення за замовчуванням ("Student", "Group", 1) та продовжує роботу.
Непередбачувані збої: Усі інші глобальні помилки в режимі demo перехоплюються загальним блоком except Exception as e, який виводить текст помилки в консоль (Невідома помилка: ...), запобігаючи аварійному завершенню (Crash) інтерпретатора.
